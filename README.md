# minisitee.com

Landing page estática do minisitee — *transforme seu Instagram em uma máquina de vendas*.

Site institucional: catálogo com foto e preço, botão de WhatsApp, horário e endereço em um link só na bio.

## Estrutura

| Arquivo | Descrição |
| --- | --- |
| `index.html` | Página principal |
| `termos.html` | Termos de uso |
| `privacidade.html` | Política de privacidade |
| `cookies.html` | Política de cookies |
| `styles.css` | Estilos do site |
| `script.js` | Interações da página |
| `favicon.svg` | Ícone do site |
| `og.png` | Imagem de compartilhamento (Open Graph) |
| `robots.txt` | Diretivas para crawlers |
| `sitemap.xml` | Mapa do site |

HTML, CSS e JavaScript puros — sem build, sem dependências.

## Rodando localmente

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Projeto relacionado

O aplicativo (painel, autenticação, assinatura) fica em [app.minisitee.com](https://github.com/marceloneves/app.minisitee.com).
